# Cars Angular

Frontend application developed with Angular featuring JWT authentication and a complete car management system connected to a Laravel REST API.

## Backend Repository

[Cars API Laravel](https://github.com/gregoriomesafernandez-star/cars-api-laravel)

## Features

- User registration
- User login with JWT authentication
- User logout
- User identity management
- Create cars
- List cars
- View car details
- Update cars
- Delete cars
- Form validation
- Angular services
- Signals
- Responsive design
- Integration with Laravel REST API

## Technologies

- Angular 21
- TypeScript
- RxJS
- Angular Router
- Angular Forms
- Tailwind CSS 4
- PostCSS

## Installation

Clone the repository:

```bash
git clone https://github.com/gregoriomesafernandez-star/cars-angular.git
cd cars-angular
```

Install dependencies:

```bash
npm install
```

## Backend API

This application requires the Laravel Cars API to be running.

Configure the API URL according to your Laravel API setup:

```text
src/app/services/global.ts
```

Example:

```ts
export var GLOBAL = {
    url: 'http://localhost:8000/api/'
};
```

Start the development server:

```bash
ng serve
```

Open your browser at:

```text
http://localhost:4200
```

## Application Routes

| Route | Description |
|----------|-------------|
| /home | Home page |
| /login | User login |
| /register | User registration |
| /crear-coche | Create car |
| /editar-coche/:id | Edit car |
| /coche/:id | Car details |

## Authentication

User authentication is handled through JWT tokens generated by the Laravel API.
